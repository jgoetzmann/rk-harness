# Evidence for D45: per-coefficient pricing from compiled output

Validation-lab records for the epoch-2 coefficient cost rule (PLAN.md section 3, decision D45), copied from the lab work area; `headlines.json` stood at the work-area root, the rest in its `lab/` directory. `PREREG.txt` is the pre-registration written before the first traced run, holding the sha256 of the corpus and the gate script so any later change voids the run. `corpus.json` is the 44-row traced corpus itself: the nine traced methods, twelve archive records of four or fewer stages, six five/six-stage records for per-step gates only, and seventeen synthetic rows covering signed multipliers, shared products, integers, an inexact coefficient, one half, and an all-zero row. `v1_v5_report.json` is the gate report: V1 pricing equality passes over 196,600 checks with zero mismatches, V2 traced MULS equals predicted MULS on every row, V4 shows zero inversions with Spearman 1.0 on the nine anchors under both M0+ models, V5 crosscheck matches with identical C hashes, and V3 fails as run on k-reload and h-times-k residual classes that D45(h) then names as residual rather than analytic scope. `v6_report.json` is the archive totality scan: all 141,364 archived tableaus price under the candidate rule with zero KeyError, including twenty applications of the s == 0, |m| == 1 corner. `headlines.json` carries the toolchain strings, the S-independence showcase with per-shift disassembly sequences, the shift-add/MULS sweep counts, and the domain probe result.
